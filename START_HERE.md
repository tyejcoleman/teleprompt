# Copy this prompt into your Mac coding agent

Paste this into Codex, Claude Code, Cursor, or any coding agent that can use your Mac's terminal. It will ask where your script is and whether to add cues, then set everything up. You only need to allow the microphone and read.

```text
Set up this teleprompter on my Mac: https://github.com/tyejcoleman/teleprompt

Clone it into ~/teleprompt (or reuse my existing checkout), then follow "Set up for a new user" in its AGENTS.md. Ask me where my script is and whether to add delivery cues, then run node setup.mjs. Never change my spoken words. I'll allow the microphone and test my voice myself.

When I give feedback later, fix this same checkout in place (AGENTS.md explains where). Don't add a hosted site or a paid API.
```
