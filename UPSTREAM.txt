This derivative adds a studio reader, current-word highlighting, delivery cues,
script import/export and persistence, confidence-gated local alignment, explicit
recognition errors, focus and floating views, live style syncing, agent tuning
surfaces, a Mac launcher, and regression checks. Browser Web Speech API remains
the only speech provider; no required paid API or hosted deployment.
